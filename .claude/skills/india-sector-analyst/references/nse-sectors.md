# NSE Sectoral Indices - Complete Reference

## Overview

NSE maintains 13 major sectoral indices covering different segments of the Indian economy. Each index represents a specific industry group with carefully selected constituent stocks that reflect the sector's performance.

## Implementation Notes

### Data Availability
- **Real-time**: All sectoral indices available on NSE website
- **Historical**: 2+ years of daily data available
- **Constituents**: Updated quarterly by NSE

### Calculation Methodology
- **Weighted Average**: Market cap weighted (free float)
- **Base Date**: Various base dates, normalized to common scale
- **Rebalancing**: Quarterly review and annual reconstitution

### Usage in Trading
- **Sector Rotation**: Compare relative performance
- **Macro Timing**: Align with economic cycles
- **Risk Management**: Diversify across sectors
- **Options Trading**: Sector index options available
