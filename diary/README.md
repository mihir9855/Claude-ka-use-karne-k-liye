# Khana Diary

Tell it what you ate, like a message: "poha, chai, dal tadka". It remembers, adds calories and protein for dishes it knows, and builds a menu for the rest of your day from your own habits.

- **Chat**: type only the names. The app replies with the day's running calories and protein. Tap a message to remove it.
- **Menu**: below the chat, one dish for each meal still to come. Tap a dish to see another option, tap the tick when you eat it.
- **What I have learned** (top right): your usual dish for each meal, targets, recent days, sample meals and delete-all.

Data stays on the phone. Run `npm test` for the logic tests and `npm run web` for a browser preview. The APK is built by hand from the "Build Khana Diary APK" workflow in GitHub Actions.
