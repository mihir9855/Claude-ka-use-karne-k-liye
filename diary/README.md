# Khana Diary

A food diary that remembers. Type only the names of what you ate ("poha, chai, dal tadka"), and the app keeps them, adds calories and protein for dishes it knows, and suggests what to eat next from your own habits.

- **Log**: names only, pick the meal, add. Today, yesterday and two days ago.
- **Next**: three dishes for the meal you choose. Often-eaten dishes rank first, what you ate today ranks lower, and missing protein or calories pull the right dishes up.
- **Learned**: your usual dish for each meal, targets, recent days, sample meals and delete-all.

Data stays on the phone. Run `npm test` for the logic tests and `npm run web` for a browser preview. The APK is built by hand from the "Build Khana Diary APK" workflow in GitHub Actions.
